# CreditWise — AI-Powered Loan Approval Prediction System

CreditWise is a full-stack machine learning web application that predicts loan approval eligibility using applicant financial and demographic information.

The project combines a trained ML model, Flask backend API, & modern React frontend to deliver real-time loan approval predictions with an interactive user experience.

## Features

* Real-time loan approval prediction
* Full-stack ML deployment
* Flask REST API backend
* React + Vite frontend
* SHAP-inspired prediction insights
* Responsive modern UI
* Probability/confidence scoring
* Production-ready deployment architecture

## ML Pipeline

Built an end-to-end supervised ML pipeline using:

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Naive Bayes
* XGBoost
* Stacking Ensemble Techniques

The model predicts loan approval probability based on this features:

* Income
* Credit score
* Loan amount
* Savings
* Employment status
* Existing loans
* Collateral value
* Demographic features
